## 2. 方法概要（F2）

```
灰度 SAR 图像，拉伸到 512×512，用训练集的均值 / 标准差归一化
  → DINOv3 ViT-B/16（冻结）+ LoRA r32，加在全部 12 个 block 的 qkv / proj / fc1 / fc2 上，LayerNorm 也训练
  → 32×32 个 token，每个 768 维
      ├─ token 取平均 → LayerNorm + Linear → 图像类别（9 类）
      └─ ViTDet 简单特征金字塔（步长 4 / 8 / 16 / 32 / 64）
           → RPN（NWD 匹配，最小锚框 6 像素）
           → 3 阶段 Cascade R-CNN（IoU 阈值随目标尺寸变化，即 A4）→ 框、类别、分数
```

- **训练**：
  - 全部 9,392 张有标注图，100 轮。
  - AdamW，weight decay 0.05；LoRA 学习率 3e-4，检测头 1e-4；1 轮 warmup 后余弦降到 0。
  - batch 16，bf16，`torch.compile`。
  - 增强只用翻转，并带 A2 翻转偏差修正（`--flip-bias -0.3`）。
- **推理**：每张图前向一次，然后后处理：
  - 框分数 × RPN objectness^0.25，按类 soft-NMS（σ 0.75）。
  - 框取三个 Cascade 阶段的平均。
  - 分数阈值 1e-5，每张图保留 30 到 100 个框。
  - 分类结合检测结果：argmax(log p_分类 + log 该类最高检测概率)。
  - 所有框平移 −0.2 像素。

### 3.6 验证方式，以及怎样选 Phase 2 提交

- **本地划分**：`prepare_course_data.py` 按类别分层，用固定种子 0，从 9,392 张有标注图里切出 train 7,512 / val 940 / test 940 张。val 和 test 两个留出集都用来评估。官方的 val / test 图片只用于预测，从未训练、标注或调参。
- **本地基准**：本地划分和官方不同，训练数据也只有 80%，所以先在本地复现参考模型（E00），本地 Δm 以它为基准。
- **采用标准**：一项改动要在本地 val 和 test 两个留出集上都提升，平均 mAP 至少 +0.4，才采用。
- **防止对本地数据调参**：后处理的超参数只在少数几个粗粒度值里选（例如 λ ∈ {0, 0.5, 1}），并且要在 3 个模型 × 2 个留出集上方向一致。
- **和排行榜校准**：本地分数会高估排行榜，原因有两个：本地有近似重复图；类别比例也不同，排行榜 val 里风机和机场更多，桥和港口更少。所以本地分数只用来比较方案，绝对水平以排行榜为准。
- **最终模型**：用全部 9,392 张训练，没有留出集。轮数（100）来自 V2 实验：V2 在本地 train + val 上训练 120 轮，用本地 test 监控，第 90 轮后进入平台期，第 100 轮最好。
- **Phase 2 的选择（建议写法）**：Phase 2 用 Phase 1 排行榜上最好的模型（目前是 F2）。新模型只有在本地两个留出集上都超过 F2，并且在 Phase 1 排行榜上也超过 F2，才替换 F2。

| A4 | 12.9 | 20.7 | 28.2 | 50.4 | 47.6 |
| A4b | 12.5 | 21.3 | 29.6 | 49.8 | 47.8 |

## 5. 方法演进：每一步做了什么、为什么这样选

### 5.1 出发点

**指标**：Δm = ½ × [(F1 − F1_ref) / F1_ref + (mAP − mAP_ref) / mAP_ref] × 100。官方参考 mAP 很低（26.13），所以 mAP 每涨 1 个点，Δm 涨约 1.9；F1 每涨 1 个点，Δm 只涨约 0.54，前者约是后者的 3.6 倍。分类已经在 93–96 之间接近饱和，**整个优化的重心是检测 mAP**。

**数据**：
- 9 个类别，9,392 张有标注的 SAR 图像。
- 70% 的框属于 COCO 定义的小目标。按 512 输入算，一半的框边长不到 16 像素，也就是小于一个 ViT patch。风机、桥梁、油罐的中位边长只有 8–12 像素。
- 桥梁和操场的 AP 一开始几乎为 0。看了图像，标注没有错：桥梁是河流和道路交叉处 6–10 像素的小点，操场是密集城区里约 15 像素的小块。

**规则约束**决定了哪些路能走：总参数 ≤130M，可训练 ≤40M（含检测头）；单模型，不能集成或 TTA；每张图只输入一次，≤512，不切块；不能用其他 SAR 数据或 SAR 预训练模型；不能在 val / test 图像上训练。

### 5.3 每个阶段的细节和取舍

#### 阶段 1：选骨干

- **试了什么**：DINOv3 ViT-B/16（E01）；DINOv3 ConvNeXt-T 全量微调（E07）；计划过 DINOv3 ConvNeXt-B（E03）和 DINOv2 ViT-B/14。
- **结果**：只换骨干，DINOv3 ViT-B/16 就带来 +8.1 Δm（加后处理 +10.9），当时是最大的单项提升。
- **ViT 还是 ConvNeXt-T 全量微调**：ConvNeXt-T 加检测头一共只有 35.5M，可以在 40M 上限内全部训练，参考代码里全量微调比 LoRA 高约 13.5 Δm，看起来很有吸引力。实测只有 +6.8：ConvNeXt 虽然有步长 4 的高分辨率特征，<8 像素目标 AP 只有 1.9，比参考还低。所以 DINOv3 在小目标上弱是预训练本身造成的，和结构无关。结论：86M 的大模型冻结 + LoRA，胜过 35M 小模型全量微调。
- **DINOv2 ViT-B/14**：patch 14 在 512 输入下无法整除，特征网格和锚框会错位，没有用。
- **代价**：DINOv3 在 16 像素以上明显更强，但在 16 像素以下比 IN21k 差。后面的检测头和 A4 主要在补这块。

#### 阶段 2：适配方式（LoRA 加在哪、多宽）

- **试了什么**：E02（IN21k，LoRA 扩到 qkv / proj / fc1 / fc2，秩 32，训练 LayerNorm，学习率 3e-4）；E09b（调研建议的“宽 LoRA”：DINOv3 + 秩 64 + LoRA+ ×2 + drop path 0.1，偏置和 layer scale 也训练）；E04r（DINOv3 + E02 原样的配方）；D6（E04r 的秩改为 64）。
- **结果**：只扩大适配容量（E02，+11.4）比只换骨干（+8.1）收益更大。E09b 分类最好（F1 95.2），检测却比 E01 还差。诊断实验 E04r 证明问题出在 E09b 额外加的设置（drop path、LoRA+、更强的正则），而不是 DINOv3 本身。E04r 得到 +18.1，两个留出集一致，成为后面所有实验的基础。
- **秩 32 还是 64**：r64 只多 +0.6，在噪声内，还要多占 4.7M 可训练参数。选 r32，把预算留给检测头。
- **LayerNorm 训练，patch embedding 不训练**：LayerNorm 参数很少，能让特征分布适应 SAR；patch embedding 以小学习率训练（S6）只有很小的收益。

#### 阶段 3：检测头和小目标

每次只在 E04r 上改一项，24 轮。

- **Cascade R-CNN（D1）**：3 个阶段（IoU 0.5 / 0.6 / 0.7），轻量的类无关框头，RoIAlign 对齐像素中心。mAP 在 val / test 上 +1.39 / +1.23；IN21k 上的对照 V1 也有 +1.6。动机是定位精度：AP50 和 AP75 差距很大（飞机 71 对 16，风机 46 对 4），8 像素的风机要 IoU 0.75，定位需要精确到约 1 像素。框头是轻量的，可训练参数反而少了约 1M（23.8M 对 24.9M）。
- **NWD 匹配和小锚框（D2）**：RPN 按 max(IoU, NWD) 匹配，C = 8，最小锚框 6 像素，锚框中心对齐像素。8 像素的框偏几个像素 IoU 就几乎为 0，正样本会被丢掉；NWD 把框看成高斯分布算距离，对小框宽容得多。Δm +1.6（mAP +0.88 / +0.57）。
- **放弃的几项**：
  - CNN 空间先验 + 多层特征颈部（D3）：24 轮下大幅变差，主要是多层颈部让最高分辨率的特征来自浅层 block，语义太弱。只加空间先验（S5）在 36 轮下是 +1.76 Δm，结果出来时 F2 已经开训，所以是下一版的首选。
  - D4 旋转翻转 + 同类复制粘贴（D4）：大幅变差；100 轮长训练里又测了一次（L1），也没用。
  - Mona 适配器（D5）：启动时 cuDNN 报错，当时有更有把握的方向，就没有再修。

#### 阶段 4：训练长度（单项最大的提升）

- 同一配方从 24 轮延长到 36 轮（L36），本地 Δm 从 +18.1 升到 +29.4；加上 Cascade + NWD 后 36 轮（C36）+31.3，48 轮（C48）+38.6。
- V2：两卡 DDP，余弦 120 轮，本地 train + val 训练、本地 test 监控（曲线见 4.3）。第 90 轮以后进入平台期，没有明显过拟合。
- **选 100 轮**：100 到 120 轮只差约 0.4，在 940 张集合的噪声范围内，100 轮更省时。
- **余弦降到 0，不用 EMA**：学习率降到 0 时模型已被平滑，EMA（E1）基本打平。
- **两卡 DDP**：全局 batch 16 不变，速度从每秒 37 张到 72 张，100 轮从 7 小时缩到 3.6 小时，后面的全量训练才来得及做。

#### 阶段 5：后处理

逐项效果和理由见 4.4。原则：都只作用于同一次前向传播，不是集成或 TTA；每一项都要在多个模型、两个留出集上方向一致才采用。

#### 阶段 6：全量数据（F1）

- V2 配方，用全部 9,392 张训练 100 轮，不留任何本地留出集。Codabench val 41.26，比 V2 第 100 轮（38.23）高 3.03：mAP +1.35，F1 +0.84。
- **取舍**：用全部数据就没有留出集可以监控或挑检查点。可行是因为 V2 已经证明 100 轮是平台期、不会过拟合，直接取最后一轮；多 940 张数据（+11%）比保留监控能力更重要。

#### 阶段 7：精修，F1 → F2

改动都在 36 轮的 C36 配方上筛选，结果见 4.2。

**A4：Cascade IoU 阈值随目标尺寸变化**（`--cascade-size-iou`）

默认的 0.5 / 0.6 / 0.7 下，小目标在第 2、3 阶段几乎没有正样本。A4 对小目标放宽：

| 目标边长 | 三个阶段的 IoU 阈值 |
|---|---|
| < 8 像素 | 0.40 / 0.45 / 0.50 |
| 8–16 像素 | 0.45 / 0.50 / 0.55 |
| 16–32 像素 | 0.50 / 0.55 / 0.65 |
| 更大 | 0.5 / 0.6 / 0.7（不变） |

- 结果 mAP +0.93 / +0.74（相对 C36 单次运行）。按尺寸看（4.5），小目标大涨，32–96 像素掉了 2 个点。
- **取舍**：为了保住中等目标试了 A4b（只对 16 像素以下放宽）。A4b 的 32–96 像素照样掉了 2.6，总分反而比 A4 低约 0.35。说明中等目标的损失不是它们自己的阈值造成的，而是小目标新增的低 IoU 正样本影响了共享的分类头。A4 净收益最大，保留。

**A2：翻转偏差修正**（`--flip-bias -0.3`）

- **发现**：把预测框整体平移 −0.4 像素（512 输入下），3 个模型、2 个留出集上 mAP 都稳定提高。
- **排除其他解释**：分开平移左上 / 右下角、分开平移 x / y、按原图尺寸换算，最优都还是统一 −0.4，其他方案差别不超过 ±0.02。折合原图约 −0.3 像素，在 512 和 256 两种原图上一致，最可能是标注坐标约定造成的系统偏差。
- **推论**：翻转增强会把这个偏差变成相反方向，同一个目标的回归目标在 ±0.3 像素之间来回摆动，对 <8 像素的目标影响不小。
- **做法**：翻转时把框额外挪动两倍的偏差，让所有训练目标保持同一种坐标约定。
- **结果**：mAP +0.64 / +0.57，而且不再需要 −0.4 平移，验证了上面的解释。A2 模型再加 −0.2 像素平移，val / test 各多 +0.2 mAP；+0.2 方向则不好。所以 F2 用 −0.2。

**两项能不能叠加（AA）**：相比 C36 均值是 +2.27 Δm（38.43 / 40.01 mAP），能叠加，但比两项单独收益之和小。

**F2 的排行榜结果**：

| | Δm | macro-F1 | mAP | AP50 |
|---|---|---|---|---|
| F1 | 41.26 | 95.90 | 46.97 | 71.57 |
| F2（shift −0.2） | **44.84** | 95.46 | **48.97** | 71.53 |

- mAP +2.00，比本地 36 轮实验估计的 +1.0 还大，可能是因为排行榜 val 的小目标类别（风机）更多。
- F1 −0.44，只损失约 0.24 Δm。
- AP50 不变，提升全部来自更高 IoU 阈值下的定位精度，正好是 A4 和 A2 针对的问题。

### 5.4 试过但没采用的方向

| 实验 | 改动 | 结果 | 原因 |
|---|---|---|---|
| S8 | 重叠 patch（步长 8，token 数 4 倍） | mAP −0.13 / −0.64 | 最小的类变好（桥 +0.7、操场 +1.4、风机 +1.6），但油罐从 42 掉到 35.6；计算量 2.6 倍 |
| E1 | 权重 EMA | 打平 | 余弦降到 0 后没有额外的平滑作用 |
| B1 | IoU 质量分支 | 打平；重打分变差 | 用预测 IoU 重新打分越强越差 |
| R1 | NWD 常数 8 → 16 | test 上不明显 | 噪声范围内 |
| R2 | 每张图 RoI 采样 512 → 1024 | 约 −2 mAP | 明显变差，没有再深究原因 |
| S6 | 训练 patch embedding | 很小 | 不值得 |
| N1 | 最后 2 个 block 全量训练 | 小幅正收益 | 可训练参数到 37.2M，接近 40M 上限 |
| L1 / L2 | 100 轮 + D4 增强 / + 随机放大 | 低于 V2 | 两种增强都没用 |
| E07 | ConvNeXt-T 全量微调 | +6.8 | 见阶段 1 |
| D3 / D4 | 多层颈部 / D4 增强 + 复制粘贴 | 大幅变差 | 见阶段 3 |

### 5.5 贯穿始终的几个原则

1. **先看指标结构再定方向**。mAP 对 Δm 的影响是 F1 的 3.6 倍，所以绝大多数 GPU 时间花在检测上。
2. **每次只改一项，在当前最好的配方上做**。E09b 把多项设置混在一起，检测变差后又花了一次诊断实验（E04r）才找出原因，之后都严格单项筛选。
3. **看分解结果，不只看总分**。按尺寸、按类别看 AP，才发现 DINOv3 在小目标上弱、定位精度是瓶颈、A4 有中等目标的代价。
4. **规则优先**。所有后处理都只作用于同一次前向传播；最终模型可训练 23.8M、总参数 109.0M，离 40M / 130M 上限都留了余量。
5. **两个留出集都要提升，再用排行榜校准**。每一项被采用的改动，最后在排行榜上也确实带来了提升：V2 38.23 → F1 41.26 → F2 44.84。

## 6. 效率

- 可训练参数 23.8M，是上限 40M 的 60%，只比参考模型（21.0M）多 2.8M；总参数 109.0M，参考模型是 107.0M。
- 最终模型训练约 7.2 GPU 小时，推理 17.7 ms / 张。
- 主动放弃了两个更贵但没有带来收益的方案：S8 重叠 patch（计算量 2.6 倍，变差）和 LoRA r64（可训练参数 +4.7M，只多 +0.6）。

## 7. 局限和下一步

- 本地留出集比排行榜容易（近似重复图、类别比例不同），本地只用来比较方案，绝对分数以排行榜为准。
- 桥梁和操场的 AP 仍然很低，本地只有 1–4。
- **下一步 F3 = F2 + S5（空间先验）**，视情况再加 N1。S5 在本地是 +1.76 Δm（单种子），和 A4 / A2 的作用机制不同，有望叠加；两卡全量训练约 3.6 小时。S5 的空间先验是随机初始化的；如果改用 `--pretrained-prior`（ImageNet ResNet-18），要在 3.4 节的预训练模型表里补上。
- Phase 1 在 2026-11-01 截止，Phase 2（test，只能提交 2 次）从 11-02 开始。
